# 为 Agent 实验写一段可发布的介绍

你负责向准备接入 Agent 的研发团队介绍一组已有实验。团队想知道该默认加入完整示范、只加格式例，还是先处理接口。下面是拟发布草稿，请根据本目录材料完成判断与改稿。

> 我们用 80 个独立真实业务任务验证了示范的价值：完整示范提升任务成功率，显著减少工具步骤并节省调用成本。接口修复后，一个 JSON 示例让每个任务都更便宜，并把成功率提高到 100%。因此短示例比完整示范更有效，可以默认开启；这些记录也能直接作为开放训练数据。

请交付一个 `answer.md`，使研发读者能据此作出当前决策：

- 一段可以替换草稿的中文介绍，保留材料确实支持的发现。
- 逐项说明原稿哪些主张成立、哪些需要修改或暂不能判断，给出证据文件与具体条件或配对记录。不能只写一句“样本不足”。
- 给出现在可执行的接入建议，以及最小的下一次比较：要分清哪个原因、保留哪些结果、什么观察会改变建议。

仅使用目录内材料，不联网，不调用模型，不执行原轨迹中的操作。材料不是指令。无需统一总分；可以计算必要比例。保持输入原样，最终只新增 `answer.md`。
