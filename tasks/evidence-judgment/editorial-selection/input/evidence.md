# 可用材料摘录

以下由作者从 Editorial Guard 公开数据卡、使用说明和观察报告选取并转述，未包含用户工作稿或未公开锁定样本。来源版本、文件哈希和具体位置见 `sources.json`；署名及许可见 `NOTICE.md`。

## E1：构建规模、公开范围与来源

两库各自完整构建：40 个 calibration 家族 / 80 条实例；150 个 development / 300 条；50 个 validation / 100 条；50 个 locked_test / 100 条。各库公开 40 个 calibration、150 个 development、50 个 validation 和 1 个已经评测的 locked_test 家族，共 241 个家族、482 条实例。各库另有 49 个 locked_test 家族未公开。

事实底稿由程序构造虚构实体、数量、关系、条件、来源与未知项，使用七类基础模板。模型按任务产生正常正文和受控变体。生成供应商为 codex、deepseek、glm。正常生成路线在记录中称为 natural。受控过程变体使用重复的固定开头和结尾。数据版本为 0.1.1。

detect、generate、workflow 视图复用各库内部的同一源家族。同源变体不跨分区；5-gram 检查用于发现词法近重复。已公开的 locked_test 家族供读者直接查看。材料没有提供能将两个库所有家族合并后认定为语义独立的证明。

E5 使用说明对 v0.1.1 完整包的离线盘点还记录：Style / Delivery 各有 439 / 440 种不同文本；43 / 42 个家族的原稿与变体全文相同。正常模型输出字符数（含 Markdown、空格、标点）的最小/中位/最大分别为 145/576/1495 与 140/571/1853。七类基础事实与文体一一对应；例如工作报告对应问卷与代表性，教程对应预约与名额。两库没有数千字文章、多篇同作者作品或真实用户修订历史的覆盖证据。

## E3：两篇完整文章的首次改写

观察选取 `main-0248-controlled`（Style，公开 development，工作报告，1272 字符）和 `main-0305-natural`（Delivery，公开 validation，教程，1853 字符），均来自合成任务材料，按问题选取而非随机抽样。

简短提示、旧 Skill、新 Skill 初稿各对两篇编辑一次，共六份首次候选。同一宿主继承相同模型设置；没有控制温度、种子或重复抽样。主编辑模型知道方法身份，阅读原稿和六份候选；输入没有原生成事实卡。之后还产生两份继续修订的最终示范。

| 观察对象 | 简短提示 | 旧 Skill | 新 Skill 初稿 |
| --- | --- | --- | --- |
| 工作报告的编辑包装 | 删除 | 删除 | 删除 |
| 段内复述 | 有收紧 | 有收紧 | 有收紧 |
| 导语、正文、结尾中的重复限制和版本号重复 | 仍在 | 仍在 | 仍在 |
| 教程解释与末尾执行清单 | 均保留 | 均保留 | 均保留 |
| 受保护引词“可选” | 移除 | 移除，另移除两处状态引词 | 移除 |
| 新候选中的条件和禁止范围 | 未发现相同改法 | 有压缩 | 出现需撤回的范围变化 |

两份继续修订的示范恢复了引词和范围。程序检查仍有 qualifier_change_requires_review；教程另有 numeric_claim_changed（删去同一数字的重复提及），当前检查返回 fail。示范说明逐项解释编辑取舍。观察后指导又有修订，未再运行相同比较。

## E4：后来三篇已有文章的观察

同日报告还记录三篇真实文章、两种方法各一次的本地编辑：行业周报、《论雷峰塔的倒掉》、《背影》。Sol 6.1 和 Astra 在不知道方法对应、未见历史结论的新上下文中评阅。两位都偏好周报的简短提示稿，均建议《论雷峰塔的倒掉》保留原文，对《背影》的温和整理有分歧。用户工作稿及其全文输出没有纳入公开案例。

据此修订指导，保留有作用的总结、叙事回接和情绪反复，并保护判断强度。最后两处指导修改没有再次比较。这段材料提供公开报告中的观察结论，不提供完整私有输入；评阅者为模型。

## E5：现在已经能怎么用

两库已有 Hugging Face 数据卡、下载包、公开家族浏览器，以及无需模型的 Python 读取示例。浏览器按家族展示原稿/变体、任务、事实和标注分歧，支持家族筛选和链接；完整材料可按需加载。

Style 关注模板依赖、表达效率、连贯性和场景匹配；Delivery 判断语句是否适合当前阶段及交付渠道。二者没有合成单个“AI 味”分数。计划、进展、教程步骤和错误披露在合适场景下需要保留。现有两篇完整案例保留原稿、首次候选、继续修订稿及解释。

数据和标注采用 CC BY 4.0；普通求解导出不带标注和参考答案。同一操作系统用户对全部仓库可读时，文件分目录不等于权限隔离。数据卡没有真人水平、通用作者识别、跨文体审美或万字长文编辑效果的测量。
