公开的任务、智能体轨迹、可执行环境和可复现评测。2026年10月13日完成公开设置，并匿名核查全部19个发布版本的79个资产。[公开目录](docs/PUBLIC-EVALUATIONS.zh-CN.md)。

**可选研究输入：[AI 行业研究材料集](corpora/ai-industry/BROWSE.zh-CN.md)。** 按题目浏览整理后的正文、摘要和历史版本，与既有来源包关联；材料数量不计作评测任务或运行次数。

现有及以后的用户题、开发题、参考测试和案例均为真实独立任务；实际执行的测试都是真实测试。任务按研究问题区分，同题重复运行仍按重复运行记录。来源材料保留原有出处与性质，包括用户提供或构造的数据。Astra 在单独上下文中即可承担独立评审，无需外部人员、另一家模型或额外外部材料。分工、评审输入或验收标准变化时，应针对受影响部分复验。

最新数据为v0.16：统一消费包保留22条实际执行、276个步骤、91条符合既有用途条件的训练步骤和7条正向示范。9月29日四模型用途实验与格式实验分别保留48条、32条真实执行；格式实验31条通过，1条交付结构失败。原始不通过结果不会被修订稿覆盖。
