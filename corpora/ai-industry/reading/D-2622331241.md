# 一、快手AI概览

| 2016年 | 深度学习部门更名为多媒体理解组（MMU） | 涉猎语音、文字、音乐等多种媒体形式，推动AI能力从单模态向多模态内容理解升级。 |
| - | 业务体系形成 | MMU形成信息分发和人机交互两大业务体系，提升视频内容理解，辅助用户创作。 |
| 2016年下半年 | Y-Lab成立 | 宿华邀请郑文组建，类似Google X的科技实验室，从事AI和AR等领域的前沿技术研究。 |
| - | Y-Lab成果 | 开发出多种demo，覆盖AR特效、人脸识别、手势识别、语义分割等领域。 |
| - | 异构计算与芯片事业部成立 | 尝试自研AI加速芯片，解决算力问题。 |
| 2018年 | Y-Lab更名为Y-Tech | 加强产品和工程能力，实现新技术研究到产品落地的无缝对接。 |
| 2019年 | AI技术研发和产品实践升级 | 完成从实验室研究到产品商业化的闭环模式升级，推出直播电商、智能硬件等产品体系。 |
| 2020年底 | 招股书披露 | 快手披露在人工智能领域的长期投入和技术积累，支持业务增长和未来发展。 |
| 2022年3月 | 生成式AI投入 | 程一笑透露快手在生成式AI方面的多年投入和技术积累，推出“快意”、“可图”、“可灵”等自研大模型。 |
| - | 生成式AI应用推出 | 推出一系列生成式AI应用，覆盖内容生产、理解、推荐等多个层面，服务于商业生态场景。 |
| 目前 | AI战略聚焦 | 快手的AI战略聚焦于直播电商、大模型和智能硬件三大核心业务领域，通过技术创新推动商业化和用户体验提升。 |
| - | 直播电商AI应用 | 在直播电商场景下，通过提供特效、美颜、剪辑等功能，增强互动性和趣味性，提升购买意愿和转化率。 |
| - | 大模型技术应用 | 通过快意语言大模型和可灵视频生成大模型，支持内容创作、信息咨询、逻辑推理等多种任务。 |
| 2024年投资者日 | AI领域投入加大 | 快手高层表示将继续加大在AI领域的投入，实现长期业务增长和市场竞争力提升。 |
| 未来规划 | AI领域全面布局 | 强化从直播电商到大模型的全面布局，通过AI技术重塑内容与商业生态。 |
| - | 全球高质量增长 | 致力于在全球范围内实现高质量增长和商业化变现，构建智能化生态系统。 |
