# 数据集构建范围与完成标准

更新：2026-09-28。当前批次为 v0.11；已发布的最新完整包为 v0.10。交付对象持续包含任务、可观察轨迹、环境、交付文件、评分依据、参考解法、来源和用途。

本批已完成六个家族、十二个可执行任务的离线构建：两个真实归档报告家族保留开发诊断用途，四个新编合成家族分别进入 train、development、test。同源变体保持同一切分。二十四条参考执行通过，九十三条错误控制被拒绝。

当前八条纯合成实际执行及阶段导出已验证：117 次调用、4 条合格成功示范、57 个训练 transitions。四条真实报告任务等待外部处理授权；整包发布尚未完成。详见 [阶段结果](DATASET-v0.11.zh-CN.md)。

本批须完成的闭环：

1. 冻结材料、来源、切分、工具契约和评分器，确认完整修复与错误修复能够被区分。
2. 用已声明的 gpt-6-astra 采集首次执行；每题至多 48 步，总新增调用至多 576 次。先验开发任务，通过后推进其余任务。失败和预算截断保留，重跑不替换首次结果。
3. 保存每一步公开请求、动作、工具响应、文件修改、验证依据及最终 report.md / analysis.json。写入超时必须保留不确定状态、查询和重试证据。
4. 从同一批原始执行导出完整轨迹、合格成功示范、失败恢复数据和 RL transitions；开发与测试家族排除训练导出。
5. 独立解包运行参考解法、环境入口和评分脚本，拒绝重新计算哈希后的语义篡改，再绑定代码提交并发布私有数据包。

输入增量通过注册材料进入候选清单，携带来源、用途、缺失信息和机制标签。先按记录的来源、父任务及精确内容归并，再做数字归一化后的字面相似性筛查。此筛查不能证明语义独立或企业间泛化。后续批次优先补新来源和新机制；同一材料多造变体不计为新独立来源。

本批是有界研究交付任务：结果、引用、文件一致性和恢复行为可执行评分；完整开放式研究质量仍未覆盖。原始报告中的断言没有在本批重新进行外部事实核验，工作副本的错误与扰动属于合成数据。

实现、数据和发布均进入 agent-trajectory-data。research-toolkit 只有出现能够由保留证据复现的框架缺陷时才另行修改、验证和提交，两个仓库的 remote 与提交独立核对。
