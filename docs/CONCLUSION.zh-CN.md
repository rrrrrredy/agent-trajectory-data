# 当前数据结论

当前已经有可执行、可记录失败与恢复、可自动评分的最小数据集。完整历史语料及七个排错任务在 v0.4，业务环境的评分修订在 v0.5；两份包都能独立验证。任务、操作轨迹、环境、评分依据和参考解法已经一同交付。

历史部分保留 45 个冻结评审输入、221 个评审记录、四次研究运行的可见工具观察，以及九条数据处理问题链。已有缺失和 28 份截断返回继续保留缺失标记，没有补写未发生的操作或隐藏推理。

本次继续检查时发现旧业务评分器确实会误判：429 被当作读到材料，补读证据可以追溯支持旧说明，参考命令的输出也无法直接评分。v0.5 保存原反例和原评分结果，用新环境修复读取回执、时间顺序、输入失败持久化和命令格式。旧攻击仍在旧版得 1，在新版得 0；正确恢复后可以通过。

新包有 10 个修订场景、48 条脚本控制、2 条作者助手实际交互和 36 条可见处理事件。两条实际交互覆盖连续限流及并发修改后的恢复，均逐步重放通过。作者执行前已知题目和评分器，因此只属于开发集接口验证。132 项工程测试、独立解包、参考命令和八类篡改反例通过验收。

据此可以确认当前管线跑通了“冻结来源 → 生成环境 → 执行并保留失败 → 重放评分 → 不可变交付”。报告事实质量、模型在未见任务上的表现、权重训练效果和跨企业迁移都还没有得到验证。十个修订场景沿用两组来源，不能算十个新独立任务家族。

下一阶段的数据扩充应以新的独立来源、实际可观测执行和有效负对照为基础，继续自动处理与保留无法确定的状态。现有月度 8 次调用额度保持不变，未启动额外模型进程；训练用途仍受来源许可与数据完整性约束。本轮无需引入人工流程或额外平台。

交付与运行入口见 [v0.5 数据说明](DATASET-v0.5.zh-CN.md)、[RL 环境](RL-ENVIRONMENT.zh-CN.md)及[验收记录](ACCEPTANCE.zh-CN.md)。
