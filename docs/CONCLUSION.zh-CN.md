# 当前数据结论

v0.9 已把任务扩展到多文档依赖、同级证据冲突和两处主张的并发修订。24 个新场景来自 6 个合成来源家族；24 条参考执行通过，158 条错误交付对照被拒绝。未来材料在检索和读取层不可见，公开编号也不再暴露故障名称。

六条实际模型首次执行成功 6/6，共 70 次调用，步数为 13、11、8、8、16、14。模型正确保留同级证据冲突，提交 blocked 并得到奖励；两次 429 和一次修订 409 及恢复动作完整保存。训练侧导出 3 条完整模型轨迹、37 条决策，测试家族继续排除。

这批证明了具体环境契约可以区分适当保留不确定性与任务失败，也能拒绝只修一项的表面完成。每步奖励显式保存，引用绑定读取时机和版本，修复必须反映到实际状态。195 项工程测试、20 项独立执行与行为检查、14 类重算哈希后的篡改检查均通过。

任务、操作轨迹、环境、评分、参考解法和处理证据已经形成可独立运行的私有增量包。真实报告与旧运行保持原有来源身份，新版素材明确为合成；当前成功率只描述这六条开发任务。不能据此推断开放式研究质量、跨企业效果或 toolkit 的收益。

后续扩充应改变依赖深度、材料布局、操作约束及故障机制，并从历史真实资料中只提取有明确依据的可验证任务。先建立新边界及反例，再增加数量。来源家族、任务变体和实际执行次数分别统计；近重复素材和共享模板仍是当前泛化评测的限制。
