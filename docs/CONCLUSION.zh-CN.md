# 当前数据判断与下一步

首批研究任务片段数据集已经构建并独立验证，实际文件、内容与使用方式见[数据集 v0.1](DATASET-v0.1.zh-CN.md)。本版覆盖两份既有研究报告的评审子任务，以及由其来源表和主张表派生的结构检查。

已经对齐 4 条历史模型请求响应，保留其中 1 条长度截断失败；构建 2 条产物衍生检查题和 6 条合成故障题；保存 16 条脚本执行及其通过、失败结果。原始研究需求、修订说明、报告正文、登记表和对应评审全部附在同一数据包内。

本版的价值是来源、输入、行为、结果和标签依据可以一起核验。历史评审结论仍是模型判断；结构检查只判定来源编号能否对应登记表。它们都不能替代事实核查或报告质量验证。

两组来源和全部派生固定在 development，因为这些材料已经用于历史诊断。当前没有未见任务集，也没有可训练记录。4 条历史评审调用是归档导入，本次新增模型调用为 0。

旧管线的 300 条模板题、300 条脚本控制、5 条实际模型运行和部分真实会话继续保留，另行盘点，未混入本版数量。91 项测试与独立解包验证说明数据处理和验证程序可运行；数据质量判断还必须受上述任务范围限制。

后续内容缺口是完整研究的检索、撰写与修订轨迹，以及更多独立来源家族。扩充时沿用同一构建路线：先取得可对应的原始记录，再做少量有意义的变形和验证。后台服务与评测 API 继续退出主流程。
