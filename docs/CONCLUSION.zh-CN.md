# 当前数据结论

v0.10 已完成真实历史失败到可执行修复任务的闭环。三条归档故障链形成 9 个任务，六条实际模型首次执行全部成功，共 62 次调用；初态失败、实际修改、409 后的复读与重试、修复后的测试和终局评分均保留。

任务提供可运行的受限 Python 环境、公开和隐藏测试、评分脚本与参考解法。9 条参考通过，54 条错误对照被拒绝；225 项回归、20 项独立运行与行为检查、16 类重算哈希后的篡改检查通过。局部修复即使通过公开测试，仍可能被隐藏测试拒绝。

跨版本目录包含 205 条保留记录，覆盖 11 个索引组件、64 个连通来源组。它可继承前版并新增当前批次，检测已记录关系上的 train/test 交叉和用途升级。失败导出包含 25 条记录、21 个不同事件和 17 组恢复样本，其中 7 组历史可训练来源样本符合训练导出条件。三条旧预算截断保持原样。

本次三个问题家族都来自一个既有诊断来源组，新增独立来源为 0。六条新成功模型轨迹继续标为开发诊断，新增完整训练轨迹为 0；与模型是否成功分别计数。公开观察、原始证据、合成扰动、脚本参考和模型执行各自有明确标签。

管线可以继续增量构建与采集，数据价值取决于新增问题和约束是否提供新的信息。后续应从已有材料挑选不同来源的可验证问题，并用新反例检验评分器；近重复语义识别、复杂仓库执行和跨企业泛化仍未获得本轮证据。扩充当前三类复现只增加变体，不能冒充来源增长。

本版仅提交私有数据集仓库，toolkit 保持 2852444。具体材料、使用限制与执行命令见 [v0.10 数据说明](DATASET-v0.10.zh-CN.md)和[批次构建流程](BUILDING-BATCHES.zh-CN.md)。
