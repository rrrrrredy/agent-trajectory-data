# 数据生产与评测系统验收

本轮约定的数据生产与评测系统已完成实现和本地验证；不以支付、训练效果或盈利作为已经发生的事实。

| 验收项 | 结果与证据 |
|---|---|
| 独立闭源仓库 | 远端 visibility 为 PRIVATE；原 research-toolkit 保持独立 |
| 多来源任务 | 10 种场景；30 个程序家族、300 个任务；300 个脚本控制通过 |
| 真实执行记录 | 新协议 2 个模型任务、8 次调用、2 次通过；原始捕获保留 |
| 真实日志入口 | 指定会话导入 319 条可见事件；156 调用、155 返回；未补造缺失事件 |
| 持续生产 | 目录输入、来源配置、幂等、坏输入隔离和有限恢复已验证 |
| 后台运行 | 实测隐藏启动、重复启动、停止和重启；没有重复生成控制运行 |
| 失败与训练导出 | 首次失败保留、关联新尝试、权利用途检查、train-only SFT 与偏好格式；当前真实训练导出为 0 |
| 评测 API | 12 次实际本地控制试次通过；重启保留结果和额度，重复请求不重复扣减 |
| 发布管理 | 260 个非 holdout 任务可独立执行；最终专有包完成哈希检查 |
| 来源撤回 | 验证后续导出、旧包受控交付和进行中的 API 试次均被阻断 |
| 功能测试 | Windows / Python 3.11，82 项通过 |

详细数据见本地 `data/production-current/acceptance-v2.json`。第一份验收收据将 development 误写为 dev，已保留原文件并通过新收据修正统计键；实际家族切分从未更改。

后台实测发现 Windows 短暂读取锁会使原子状态替换失败，已增加有限本地重试并验证。模型调用不因这个文件重试而重复。首次失败进程日志保留。

300 个任务共享 10 种模板。模型实验只覆盖其中两个场景，不能据此证明全部任务的模型表现或付费区分度。真实会话没有冻结的外部环境，不能宣称完整可重放或直接可训练。

对外网站、商户支付和生产公网部署不在本轮已完成事实中；它们需要明确的部署范围、商户账户和真实交易。产品结构、自助商业验证、价格实验和成本边界已在完整方案给出，没有安排人工访谈或人工生产队列。
